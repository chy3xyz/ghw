What GHW actually is

GHW is a paradigm, not a chatbot framework. It runs as a single daemon process (5.9 MB, RSS ≈ 4.5 MB after 13 hours) that loops forever, scoring every state by a closed-form equation, and rewriting its own code modules when the equation says it should.

The E equation

E = α·M + β·R + γ·N − μ·Var + ν·min + σ·S + λ·D
Mmethod library
Rresources
Ngoal graph
Varvariance penalty
minweakest palace
Speer E average
D9-relation depth
α, β, γ are sacred — they define the equation. μ, ν, σ, λ can be proposed by the LLM and accepted or rejected by the equation itself.

The 9-palace state

Every cycle, the daemon scores nine sub-systems in a 3×3 grid. When all nine are strong, E saturates at 1.000 and the system enters a "稳态意识" (steady-state consciousness) regime — observable in a 13-hour run as hit_rate = 1.000, miss_streak = 0.

How self-evolution works

GHW has five levels of self-rewriting, each more ambitious than the last. Every level is gated by the equation, the guard, and a real compile step.

L1
Parameter tuning
Adjusts weights in a numeric vector, no code change.
→ 4 E-formula coefficients (μ, ν, σ, λ) shift ±0.05/cycle
L2
LLM-proposed code variants
The LLM generates N candidate snippets, the guard filters, the equation picks.
→ MockLLM / ShellLLM / HttpLLM (Anthropic · OpenAI · DeepSeek)
L3
New method generation
Writes a new .zig file in /tmp/ghw_evolved/l3_*.zig and registers it.
→ 18 L3 files produced in the long-run dataset
L4
Algorithmic optimization
Replaces a hot-path function in the goal graph; gated by a closed-loop ΔE test.
→ 22 L4 files; L4 closed-loop 4 coefficients adaptive verified over 13h
L5
Rule synthesis
Self-Encoder composes a new Module from existing rules, formal-verifies, and adopts.
→ 8 L5 modules shipped; no external dependency added

The 17-blacklist guard

Before any L1–L5 output is adopted, it must pass a static-pattern check. Patterns like rm -rf /, curl | sh, fork bombs, and network exfiltration are rejected without ever running the candidate.

How GHW differs from other "agent frameworks"

Most agentic frameworks treat the LLM as the brain. GHW treats the LLM as a proposer whose output is gated by a closed-form equation.

Get started in 4 commands

You need Zig ≥ 0.17.0-dev.704, macOS or Linux, and 2 minutes.

Clone
git clone https://github.com/Knot3-Labs/ghw.git
cd ghw
Build the daemon (5.9 MB, statically linked)
zig build
Run 100 cycles and watch E converge
./zig-out/bin/daemon --cycles 100
Or, start a long-running instance and query it
./zig-out/bin/daemon --cycles 0 &        # run forever
./zig-out/bin/daemon --query-state tick    # ask "how is the world?"

Want the LLM-proposer mode?

Set the API key env var and pick a provider. The daemon will use the LLM as a proposer; the equation remains the decider.

export ANTHROPIC_API_KEY=sk-...
./zig-out/bin/daemon --llm anthropic --model claude-3-5-sonnet

Want multi-GHW cross-host communication?

./zig-out/bin/daemon --cross-host-port 9879 --cross-host-secret shared_secret_alpha
# on another host:
./zig-out/bin/daemon --cross-host-port 9880 \
    --cross-host-secret shared_secret_bravo \
    --cross-host-peers peers.txt --id bravo
